Comment télécharger un jeu

Le téléchargement se fait toujours sur un site externe (MediaFire, Google Drive...). Voici comment faire, selon le type de jeu.

APK (Android)

  1. Appuie sur "Télécharger maintenant" une fois le compte à rebours terminé
  2. Tu arrives sur le site externe (souvent MediaFire) — cherche le gros bouton vert "Télécharger", ignore les autres boutons colorés autour, ce sont des publicités
  3. Le fichier .apk se télécharge dans ton dossier "Téléchargements"

Mod APK

  1. Même principe qu'un APK classique
  2. Certains mods ont plusieurs fichiers (jeu + données) — télécharge bien tous les liens indiqués sur la fiche du jeu

ROMs / ISO (PSP, PPSSPP...)

  1. Le fichier téléchargé est une image du jeu (.iso ou .cso), pas une application
  2. Il te faudra un émulateur pour le lancer — c'est expliqué dans la section vidéos ci-dessous
  3. Sur MediaFire, attends bien le décompte avant de cliquer sur le bouton de téléchargement réel
